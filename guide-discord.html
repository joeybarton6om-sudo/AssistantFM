🤖 Méthode A — Créer un bot (automatique)

Recommandé si tu veux appliquer toute la structure d'un coup via le script fourni.

1Créer l'application

Va sur discord.com/developers/applications → New Application → nomme-la Assistant FM.

Assistant FM
Create

2Créer le bot et récupérer le token

Dans le menu de gauche → Bot → Add Bot → Reset Token → copie le token.

⚠️ Ne partage jamais ce token. Il donne un accès complet au bot. Régénère-le s'il a fuité.
••••••••••••••••••••••••••••••••••••••••
Reset Token Copy

3Inviter le bot sur le serveur

Menu OAuth2 → URL Generator :

  • Scopes : coche bot et applications.commands
  • Bot Permissions : coche Manage Channels, Manage Roles, View Channels, Send Messages, Read Message History, Embed Links, Attach Files

Copie l'URL générée, ouvre-la dans ton navigateur, choisis ton serveur et valide.

4Lancer le script

Dans un terminal, à la racine du projet Assistant FM :

python -m pip install discord.py

$env:DISCORD_TOKEN = "COLLE_TON_TOKEN_ICI"
$env:DISCORD_GUILD_ID = "ID_DE_TON_SERVEUR"   # optionnel
python reorganiser_discord.py
💡 Pour trouver l'ID du serveur : Paramètres Discord → Avancé → active le Mode développeur, puis clic droit sur l'icône du serveur → Copier l'identifiant du serveur.

5Vérifier

Le script affiche Réorganisation terminée. et crée les catégories/salons. Les anciens salons ne sont pas supprimés : range-les ou supprime-les manuellement.

✋ Méthode B — Configuration manuelle

Si tu ne veux pas créer de bot, suis ces étapes dans les paramètres du serveur.

1Créer les catégories

Dans la liste des salons → clic droit → Créer une catégorie. Nomme-les exactement :

🏠 ACCUEIL
💬 DISCUSSION
🛠️ SUPPORT
📚 RESSOURCES

2Créer les salons dans chaque catégorie

Clic droit sur la catégorie → Créer un salon → type Texte → colle le nom avec l'emoji. Répète pour chaque salon.

📖 ma-partie

🛠️ Dépannage

Le bot ne crée rien

  • Vérifie que le bot a bien été invité avec Manage Channels.
  • Vérifie que le rôle du bot est au-dessus des rôles à modifier.
  • Le token doit être valide et la variable DISCORD_TOKEN définie.

« Missing Permissions » / « Forbidden »

Le bot n'a pas les droits. Réinvite-le avec les permissions complètes ou déplace son rôle en haut de la liste des rôles.

Les salons existent en double

Le script ne supprime pas les anciens salons. Supprime-les manuellement ou renomme-les avant de relancer.

📌 Rappel : Discord n'autorise pas de police personnalisée pour les noms de salons. Les emojis + noms courts sont la meilleure solution. Garde le nom du serveur en « Assistant FM » pour rester lisible partout.
